# FalkorDB Canvas has moved

`@falkordb/canvas` now lives in the FalkorDB UI monorepo:
**[FalkorDB/falkordb-ui → `web-components/canvas`](https://github.com/FalkorDB/falkordb-ui/tree/main/web-components/canvas)**.

This repository is no longer maintained. Its history was carried over to the new location.

## What this means for you

- **Installing and upgrading work as before.** The npm package name is unchanged, and new versions are published from FalkorDB/falkordb-ui, starting with 0.2.9:

  ```bash
  npm install @falkordb/canvas
  ```

- **Documentation:** see the [canvas README](https://github.com/FalkorDB/falkordb-ui/blob/main/web-components/canvas/README.md).
- **Bugs and feature requests:** open an issue in [FalkorDB/falkordb-ui](https://github.com/FalkorDB/falkordb-ui/issues).
- **Contributions:** open pull requests against [FalkorDB/falkordb-ui](https://github.com/FalkorDB/falkordb-ui).
